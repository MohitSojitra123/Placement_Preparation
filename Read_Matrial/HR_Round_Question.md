### 15. 🔐 What is JWT?

**Answer:**

JWT stands for JSON Web Token.

It is commonly used for authentication.

After successful login, the server generates a token. The client sends this token with future requests, and the server verifies it before allowing access to protected resources.

---

### 16. 🎭 What is role-based access?

**Answer:**

Role-based access means giving different permissions to users according to their roles.

For example:

- 👑 **Admin** → manages the system
- 🧑‍💼 **Coordinator** → manages assigned events
- 🎓 **Student** → registers and participates in events

This helps protect restricted functionality.

---

### 17. 🌐 What is a REST API?

**Answer:**

A REST API is an API style used for communication between client and server using HTTP methods.

Common methods are:

- 📥 **GET** → retrieve data
- ➕ **POST** → create data
- ✏️ **PUT/PATCH** → update data
- 🗑️ **DELETE** → remove data

In my project, REST APIs were used to communicate between the React frontend and backend.

---

### 18. 🍃 Why did you use MongoDB?

**Answer:**

MongoDB is a NoSQL database that stores data in document format.

I used MongoDB because it works well with JavaScript-based applications and provides a flexible structure for storing application data.

### 20. 🪝 Why did you use React Hooks in AudioFlow?

**Answer:**

Hooks allow functional components to manage state and lifecycle-related functionality.

For example:

- 📦 **useState** → manages component state
- ⚙️ **useEffect** → handles side effects
- 🔗 **useContext** → shares data between components without passing props through every level
