## 3. Key Projects — Talking Points

### Frolic Event Management System (MERN Stack)
- **What it does:** Manages institutes, departments, events, and multiple user roles (Admin, Coordinator, Student).
- **Key features:** JWT authentication, REST APIs, MongoDB integration, event registration, group & participant management, attendance tracking, payments, winner declaration.
- **What to highlight:** End-to-end ownership — frontend, backend, API design, authentication, and database schema together.
- **Likely follow-up questions to prepare for:**
  - How does JWT authentication work in your project?
  - How did you design the database schema for roles (Admin/Coordinator/Student)?
  - How did you handle payments and ensure data consistency?
  - What was the most challenging part of this project and how did you solve it?

### AudioFlow (React.js)
- **What it does:** A React-based application focused on UI/UX and component architecture.
- **Key features:** React Hooks (useState, useEffect, useContext), component-based architecture, reusable components, responsive design.
- **Likely follow-up questions:**
  - What is the difference between useState and useContext, and why did you use useContext here?
  - How did you make the UI responsive?
  - How do you manage state across multiple components?

### Bus Booking System (Java & OOP)
- **What it does:** A console/Java-based booking system demonstrating strong OOP fundamentals.
- **Key concepts applied:** Encapsulation, inheritance, polymorphism, abstraction, exception handling, multithreading, file I/O.
- **Likely follow-up questions:**
  - Can you explain each OOP pillar with an example from this project?
  - Why and where did you use multithreading?
  - How did you handle exceptions and file operations?
