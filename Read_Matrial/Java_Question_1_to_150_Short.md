## 🖥️ Java Platform

### 1️⃣ Why is Java so popular? 🌟
Java is popular because it is **simple, object-oriented, platform-independent, secure, and robust**. Code written once (`.java`) is compiled into bytecode (`.class`) that runs on **any device** with a JVM — "Write Once, Run Anywhere" (WORA). It also has a huge ecosystem (Spring, Hibernate), strong community support, automatic memory management (Garbage Collection), and built-in multithreading support.

```java
// The same .class file runs on Windows, Linux, Mac without changes
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### 2️⃣ What is platform independence? 🌍
It means a program compiled on **one operating system can run on any other OS** without modification, because Java doesn't compile directly to machine code — it compiles to **bytecode**, which is interpreted/executed by the JVM specific to each OS.

```
MyProgram.java  --(javac)-->  MyProgram.class (bytecode)
                                     |
                 -----------------------------------------
                 |                  |                    |
             JVM (Windows)      JVM (Linux)          JVM (Mac)
```

### 3️⃣ What is bytecode? 🔢
Bytecode is the **intermediate, platform-neutral code** (`.class` file) generated by the Java compiler (`javac`). It is not human-readable machine code, but a set of instructions the JVM understands and executes.

```bash
javac Hello.java     # produces Hello.class (bytecode)
java Hello           # JVM reads bytecode and runs it
```

### 4️⃣ Compare JDK vs JVM vs JRE 🧰
| Term | Full Form | Contains | Purpose |
|------|-----------|----------|---------|
| 🛠️ **JDK** | Java Development Kit | JRE + compilers + debuggers + tools | For **developing** Java apps |
| 📦 **JRE** | Java Runtime Environment | JVM + libraries | For **running** Java apps |
| ⚙️ **JVM** | Java Virtual Machine | Bytecode interpreter/executor | **Executes** bytecode |

Simple analogy: **JVM** is the engine, **JRE** is the engine + car body needed to drive, **JDK** is the entire factory (JRE + tools) needed to build and drive the car.

### 5️⃣ What are the important differences between C++ and Java? ⚖️
| Feature | C++ | Java |
|---------|-----|------|
| Platform | Compiles to native machine code (platform dependent) | Compiles to bytecode (platform independent) |
| Memory management | Manual (`new`/`delete`) | Automatic (Garbage Collector) |
| Pointers | Explicit pointers | No explicit pointers |
| Multiple Inheritance | Supported (classes) | Not supported for classes, only via interfaces |
| Operator Overloading | Supported | Not supported |

### 6️⃣ What is the role of a classloader in Java? 📥
The **ClassLoader** dynamically loads `.class` files into the JVM memory at runtime, when a class is referenced for the first time. Java has 3 built-in loaders working in a hierarchy: **Bootstrap → Extension → Application (System)** ClassLoader.

```java
public class ClassLoaderDemo {
    public static void main(String[] args) {
        System.out.println(ClassLoaderDemo.class.getClassLoader());
        // prints something like: sun.misc.Launcher$AppClassLoader
    }
}
```

## 📦 Wrapper Classes

### 7️⃣ What are Wrapper classes? 🎁
Wrapper classes provide an **object representation for primitive data types**. Each primitive type has a corresponding wrapper class.

| Primitive | Wrapper Class |
|-----------|---------------|
| int | Integer |
| char | Character |
| double | Double |
| boolean | Boolean |
| long | Long |
| float | Float |
| byte | Byte |
| short | Short |

```java
int a = 10;
Integer wrappedA = a; // autoboxed into wrapper class
```

### 8️⃣ Why do we need Wrapper classes in Java? 🤔
Because **Collections (like `ArrayList`) and Generics only work with Objects**, not primitives. Wrapper classes let primitives be used as objects, stored in collections, passed where an `Object` is expected, and provide utility methods like `parseInt()`, `compareTo()`, etc.

```java
List<Integer> numbers = new ArrayList<>(); // can't use List<int>
numbers.add(5); // autoboxed
```

### 9️⃣ What are the different ways of creating Wrapper class instances? 🏗️
1. Using a **constructor** (deprecated since Java 9)
2. Using the **valueOf()** static factory method
3. Via **autoboxing** (implicit)

```java
Integer a = new Integer(10);      // ❌ deprecated
Integer b = Integer.valueOf(10);  // ✅ recommended
Integer c = 10;                   // ✅ autoboxing
```

### 🔟 What are differences in the two ways of creating Wrapper classes? 🔍
- `new Integer(10)` **always creates a new object** in heap memory.
- `Integer.valueOf(10)` uses an **internal cache** (for values -128 to 127) and returns a cached object if available, saving memory.

```java
Integer a = Integer.valueOf(100);
Integer b = Integer.valueOf(100);
System.out.println(a == b); // true (same cached object)

Integer c = new Integer(100);
Integer d = new Integer(100);
System.out.println(c == d); // false (different objects)
```

### 1️⃣1️⃣ What is auto boxing? 📤
Autoboxing is the **automatic conversion** done by the Java compiler between a primitive type and its corresponding wrapper class object.

```java
int primitive = 25;
Integer boxed = primitive; // autoboxing: int -> Integer
Integer obj = 30;
int unboxed = obj;         // auto-unboxing: Integer -> int
```

### 1️⃣2️⃣ What are the advantages of auto boxing? ✅
- Makes code **cleaner and shorter** (no manual `valueOf()`/`intValue()` calls).
- Enables primitives to work **seamlessly with Collections and Generics**.
- Reduces boilerplate when mixing primitives and objects in expressions.

```java
List<Integer> list = new ArrayList<>();
list.add(1); // no need for list.add(Integer.valueOf(1))
```

### 1️⃣3️⃣ What is casting? 🔄
Casting is **converting a value from one data type to another**.

```java
double d = 10.5;
int i = (int) d; // casting double to int -> i = 10
```

### 1️⃣4️⃣ What is implicit casting? ➡️
Also called **widening conversion** — automatically done by the compiler when converting a **smaller type to a larger type** (no data loss, no explicit code needed).

```java
int x = 100;
long y = x;    // implicit: int -> long
double z = y;  // implicit: long -> double
```

### 1️⃣5️⃣ What is explicit casting? ⬅️
Also called **narrowing conversion** — must be done manually by the programmer when converting a **larger type to a smaller type** (possible data loss).

```java
double d = 99.99;
int i = (int) d; // explicit casting needed, i = 99 (decimal lost)
```

## 🔤 Strings

### 1️⃣6️⃣ Are all Strings immutable? 🔒
Yes. Once a `String` object is created, its **value cannot be changed**. Any operation that seems to "modify" a String actually creates a **new String object**.

```java
String s = "Hello";
s.concat(" World");
System.out.println(s); // still "Hello" — original unchanged
s = s.concat(" World");
System.out.println(s); // "Hello World" — new object assigned
```

### 1️⃣7️⃣ Where are String values stored in memory? 🗄️
String literals are stored in a special memory area called the **String Constant Pool (SCP)** (part of heap since Java 7), which allows reuse of identical string literals. Strings created with `new String()` are stored in the **regular heap**, outside the pool.

```java
String a = "Java";          // stored in String Pool
String b = "Java";          // reuses same object from pool
String c = new String("Java"); // new object in heap (not pool)
System.out.println(a == b); // true
System.out.println(a == c); // false
```

### 1️⃣8️⃣ Why should you be careful about String concatenation(+) in loops? ⚠️
Because Strings are immutable, every `+` concatenation in a loop creates a **new String object**, discarding the old one. This is very **inefficient** for large loops (O(n²) time and lots of garbage for GC).

```java
String result = "";
for (int i = 0; i < 10000; i++) {
    result = result + i; // creates a new object every iteration! 🐌
}
```

### 1️⃣9️⃣ How do you solve the above problem? 🛠️
Use **`StringBuilder`** (or `StringBuffer` for thread-safety), which uses a **mutable internal character array** and modifies it in place instead of creating new objects.

```java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i); // modifies same object 🚀
}
String result = sb.toString();
```

### 2️⃣0️⃣ What are differences between String and StringBuffer? 🆚
| Feature | String | StringBuffer |
|---------|--------|---------------|
| Mutability | Immutable | Mutable |
| Thread-safety | N/A (immutable, inherently safe) | Thread-safe (synchronized methods) |
| Performance | Slower for repeated modification | Faster for repeated modification |
| Memory | New object each modification | Same object modified |

### 2️⃣1️⃣ What are differences between StringBuilder and StringBuffer? 🆚
| Feature | StringBuilder | StringBuffer |
|---------|---------------|---------------|
| Thread-safety | ❌ Not synchronized | ✅ Synchronized |
| Performance | ⚡ Faster (no sync overhead) | 🐢 Slower |
| Use case | Single-threaded code | Multi-threaded code |

```java
StringBuilder sb = new StringBuilder("Fast");  // not thread-safe
StringBuffer sf = new StringBuffer("Safe");    // thread-safe
```

### 2️⃣2️⃣ Can you give examples of different utility methods in String class? 🧰
```java
String s = "  Hello World  ";
s.trim();              // "Hello World"
s.toUpperCase();        // "  HELLO WORLD  "
s.toLowerCase();        // "  hello world  "
s.length();              // 15
s.substring(2, 7);       // "Hello"
s.replace("World", "Java"); // "  Hello Java  "
s.split(" ");            // splits into array
s.indexOf("World");      // returns index position
s.contains("Hello");     // true
s.charAt(0);              // returns character at index
String.valueOf(123);      // "123"
```

## 🏗️ Object Oriented Programming Basics

### 2️⃣3️⃣ What is a class? 🏛️
A class is a **blueprint or template** for creating objects. It defines the **state (fields)** and **behavior (methods)** that its objects will have.

```java
class Car {
    String color;   // state
    void drive() {  // behavior
        System.out.println("Car is driving");
    }
}
```

### 2️⃣4️⃣ What is an object? 📦
An object is a **real instance** of a class, created in memory, having its own actual values for the class's fields.

```java
Car myCar = new Car(); // 'myCar' is an object of class Car
myCar.color = "Red";
myCar.drive();
```

### 2️⃣5️⃣ What is state of an object? 📊
The state refers to the **values held by an object's instance variables (fields)** at a given point in time.

```java
Car car1 = new Car();
car1.color = "Blue"; // this is car1's current state
```

### 2️⃣6️⃣ What is behavior of an object? 🎬
Behavior refers to **what an object can do**, defined by its **methods**.

```java
class Dog {
    void bark() { System.out.println("Woof!"); } // behavior
}
```

### 2️⃣7️⃣ What is the super class of every class in Java? 🌳
The **`Object`** class (`java.lang.Object`) is the super class of every class in Java, whether declared explicitly or not.

```java
class Animal { } // implicitly extends Object
Animal a = new Animal();
System.out.println(a.toString()); // toString() inherited from Object
```

### 2️⃣8️⃣ Explain about toString method? 📝
`toString()` returns a **String representation of an object**. The default implementation (from `Object`) returns `ClassName@hashcode`. It's commonly **overridden** to give meaningful output.

```java
class Person {
    String name;
    Person(String name) { this.name = name; }
    @Override
    public String toString() {
        return "Person{name='" + name + "'}";
    }
}
System.out.println(new Person("Alice")); // Person{name='Alice'}
```

### 2️⃣9️⃣ What is the use of equals method in Java? ⚖️
`equals()` is used to check **logical equality** between two objects (i.e., whether they represent the same data), as opposed to `==` which checks **reference equality**.

```java
String a = new String("Hi");
String b = new String("Hi");
System.out.println(a == b);      // false (different objects)
System.out.println(a.equals(b)); // true (same content)
```

### 3️⃣0️⃣ What are the important things to consider when implementing equals method? 📋
1. **Reflexive**: `x.equals(x)` must be true.
2. **Symmetric**: `x.equals(y)` == `y.equals(x)`.
3. **Transitive**: if `x.equals(y)` and `y.equals(z)`, then `x.equals(z)`.
4. **Consistent**: repeated calls return the same result.
5. Always **override `hashCode()`** together with `equals()`.
6. Check for `null` and correct type before casting.

```java
@Override
public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof Person)) return false;
    Person p = (Person) o;
    return this.name.equals(p.name);
}
```

### 3️⃣1️⃣ What is the Hashcode method used for in Java? #️⃣
`hashCode()` returns an **integer hash value** used by hash-based collections (`HashMap`, `HashSet`) to quickly locate objects in buckets. **Equal objects must have equal hash codes.**

```java
@Override
public int hashCode() {
    return Objects.hash(name);
}
```

### 3️⃣2️⃣ Explain inheritance with examples. 🧬
Inheritance allows a class (**subclass**) to acquire fields and methods of another class (**superclass**), enabling **code reuse**.

```java
class Animal {
    void eat() { System.out.println("eating..."); }
}
class Dog extends Animal { // Dog inherits eat()
    void bark() { System.out.println("barking..."); }
}
Dog d = new Dog();
d.eat();  // inherited
d.bark(); // own method
```

### 3️⃣3️⃣ What is method overloading? 🔀
Having **multiple methods with the same name** but **different parameter lists** (number/type of parameters) within the same class. Resolved at **compile-time (static polymorphism)**.

```java
class Calculator {
    int add(int a, int b) { return a + b; }
    double add(double a, double b) { return a + b; }
    int add(int a, int b, int c) { return a + b + c; }
}
```

### 3️⃣4️⃣ What is method overriding? 🔁
When a **subclass provides its own implementation** of a method already defined in its superclass, with the **same signature**. Resolved at **runtime (dynamic polymorphism)**.

```java
class Animal {
    void sound() { System.out.println("Some sound"); }
}
class Cat extends Animal {
    @Override
    void sound() { System.out.println("Meow"); } // overridden
}
```

### 3️⃣5️⃣ Can super class reference variable hold an object of sub class? ✅
Yes! This is the foundation of **runtime polymorphism**. A superclass reference can point to a subclass object, but it can only call methods declared in the superclass (unless overridden).

```java
Animal a = new Cat(); // valid
a.sound(); // calls Cat's overridden sound() -> "Meow"
```

### 3️⃣6️⃣ Is multiple inheritance allowed in Java? ❌➡️✅
**Not with classes** (to avoid the "Diamond Problem"), but **yes with interfaces** — a class can implement multiple interfaces.

```java
interface Flyable { void fly(); }
interface Swimmable { void swim(); }
class Duck implements Flyable, Swimmable { // multiple inheritance via interfaces
    public void fly() { System.out.println("Flying"); }
    public void swim() { System.out.println("Swimming"); }
}
```

### 3️⃣7️⃣ What is an interface? 📜
An interface is a **contract** that specifies **what** a class must do, without specifying **how**. It can contain abstract methods (and since Java 8, default/static methods).

```java
interface Shape {
    double area(); // abstract method — no body
}
```

### 3️⃣8️⃣ How do you define an interface? ✍️
```java
interface Vehicle {
    void start();
    void stop();
}
```

### 3️⃣9️⃣ How do you implement an interface? 🔧
A class uses the `implements` keyword and must provide bodies for all abstract methods.

```java
class Car implements Vehicle {
    public void start() { System.out.println("Car starting"); }
    public void stop() { System.out.println("Car stopping"); }
}
```

### 4️⃣0️⃣ Can you explain a few tricky things about interfaces? 🤯
- All fields in an interface are implicitly **`public static final`** (constants).
- All methods are implicitly **`public`**.
- Since Java 8, interfaces can have **`default`** and **`static`** methods with bodies.
- Since Java 9, interfaces can have **`private`** methods (helper methods for default methods).
- A class can implement multiple interfaces, but if two have the same default method, the class **must override it** to resolve conflict.

```java
interface A { default void hello() { System.out.println("A"); } }
interface B { default void hello() { System.out.println("B"); } }
class C implements A, B {
    public void hello() { A.super.hello(); } // must resolve conflict
}
```

### 4️⃣1️⃣ Can you extend an interface? ➕
Yes, an interface can extend **one or more** other interfaces using `extends`.

```java
interface Movable { void move(); }
interface Flyable extends Movable { void fly(); }
```

### 4️⃣2️⃣ Can a class extend multiple interfaces? 🔗
A class **implements** (not extends) multiple interfaces — this is allowed and is Java's way of achieving multiple inheritance of type.

```java
class Robot implements Flyable, Swimmable { ... }
```

### 4️⃣3️⃣ What is an abstract class? 🌫️
A class declared with the `abstract` keyword that **cannot be instantiated** and may contain both **abstract methods (no body)** and **concrete methods (with body)**.

```java
abstract class Shape {
    abstract double area(); // no body
    void display() { System.out.println("This is a shape"); } // concrete
}
```

### 4️⃣4️⃣ When do you use an abstract class? 🕐
When you want to **share common code** among related classes while forcing subclasses to implement certain methods, and when classes share an **"is-a" relationship** with partial common implementation.

```java
abstract class Employee {
    String name;
    abstract double calculateSalary(); // varies per employee type
    void printName() { System.out.println(name); } // shared behavior
}
```

### 4️⃣5️⃣ How do you define an abstract method? ✍️
An abstract method has **no body** and ends with a semicolon; it must be inside an abstract class or interface.

```java
abstract class Shape {
    abstract double perimeter();
}
```

### 4️⃣6️⃣ Compare abstract class vs interface? 🆚
| Feature | Abstract Class | Interface |
|---------|-----------------|-----------|
| Methods | Abstract + concrete | Abstract (+ default/static since Java 8) |
| Fields | Any type | Only `public static final` |
| Inheritance | Single (`extends`) | Multiple (`implements`) |
| Constructor | Can have one | Cannot have one |
| Use case | Shared base implementation | Pure contract/capability |

### 4️⃣7️⃣ What is a constructor? 🏗️
A special method used to **initialize objects**, having the **same name as the class** and **no return type**. Called automatically when an object is created with `new`.

```java
class Person {
    String name;
    Person(String name) { // constructor
        this.name = name;
    }
}
```

### 4️⃣8️⃣ What is a default constructor? 🎁
If a class defines **no constructor at all**, the Java compiler automatically inserts a **no-argument default constructor** that does nothing special except call `super()`.

```java
class Simple { } // compiler adds: Simple() { super(); }
```

### 4️⃣9️⃣ Will this code compile? 🤔
```java
class Test {
    Test(int x) { }
}
class Main {
    public static void main(String[] args) {
        Test t = new Test(); // ❌ won't compile!
    }
}
```
**No.** Once you define **any** constructor explicitly, the compiler does **not** provide the default no-arg constructor. Since only `Test(int x)` exists, `new Test()` fails to compile.

### 5️⃣0️⃣ How do you call a super class constructor from a constructor? ⬆️
Using **`super(...)`** as the **first statement** in the subclass constructor.

```java
class Animal {
    Animal(String name) { System.out.println("Animal: " + name); }
}
class Dog extends Animal {
    Dog() {
        super("Generic Dog"); // calls Animal's constructor
        System.out.println("Dog created");
    }
}
```

### 5️⃣1️⃣ Will this code compile? 🤔
```java
class Animal {
    Animal(String name) { }
}
class Dog extends Animal {
    Dog() { } // ❌ won't compile!
}
```
**No.** Since `Animal` has no no-arg constructor, Java implicitly inserts `super()` in `Dog()`, but `Animal` doesn't have a no-arg constructor — causing a compile error. You must explicitly call `super("someName")`.

### 5️⃣2️⃣ What is the use of this()? 🔁
`this()` is used to call **another constructor of the same class** (constructor chaining), and must be the **first statement**.

```java
class Rectangle {
    int width, height;
    Rectangle() {
        this(1, 1); // calls Rectangle(int, int)
    }
    Rectangle(int w, int h) {
        width = w; height = h;
    }
}
```

### 5️⃣3️⃣ Can a constructor be called directly from a method? ❌
No, a constructor **cannot be called like a regular method** (e.g. `myConstructor()`). It can only be invoked via `new`, `this()`, or `super()`.

```java
class Test {
    Test() { System.out.println("constructed"); }
    void method() {
        // Test(); // ❌ Illegal - not a valid call
        new Test(); // ✅ this creates a NEW object, not "calling" the constructor
    }
}
```

### 5️⃣4️⃣ Is a super class constructor called even when there is no explicit call from a sub class constructor? ✅
Yes. If you don't explicitly call `super(...)` or `this(...)`, the compiler **automatically inserts `super()`** (calling the superclass's no-arg constructor) as the first statement.

```java
class Animal {
    Animal() { System.out.println("Animal constructor"); }
}
class Dog extends Animal {
    Dog() { System.out.println("Dog constructor"); } // implicit super() called first
}
// Output when creating new Dog():
// Animal constructor
// Dog constructor
```

## 🚀 Advanced Object Oriented Concepts

### 5️⃣5️⃣ What is polymorphism? 🎭
Polymorphism means **"many forms"** — the ability of an object to take on different behaviors depending on context. Java supports:
- **Compile-time (static)**: method overloading
- **Runtime (dynamic)**: method overriding

```java
Animal a = new Cat();
a.sound(); // behaves like a Cat at runtime (dynamic polymorphism)
```

### 5️⃣6️⃣ What is the use of instanceof operator in Java? 🔍
`instanceof` checks whether an object is an **instance of a specific class or interface**, returning `true`/`false`. Useful before casting to avoid `ClassCastException`.

```java
Animal a = new Cat();
if (a instanceof Cat) {
    Cat c = (Cat) a; // safe cast
}
```

### 5️⃣7️⃣ What is coupling? 🔗
Coupling refers to **how dependent one class/module is on another**. **Low coupling** (loose coupling) is desirable — changes in one class shouldn't force changes in another.

```java
// Tight coupling (bad)
class Car { Engine engine = new Engine(); }

// Loose coupling (good) - via interface/dependency injection
class Car {
    Engine engine;
    Car(Engine engine) { this.engine = engine; }
}
```

### 5️⃣8️⃣ What is cohesion? 🧲
Cohesion refers to **how closely related and focused the responsibilities of a single class/module are**. **High cohesion** (a class does one thing well) is desirable.

```java
// High cohesion - class does ONE job
class InvoiceCalculator {
    double calculateTotal(List<Item> items) { ... }
}
```

### 5️⃣9️⃣ What is encapsulation? 🛡️
Encapsulation means **bundling data (fields) and methods together** and **restricting direct access** to internal data using access modifiers (typically `private` fields with public getters/setters).

```java
class Account {
    private double balance; // hidden from outside
    public double getBalance() { return balance; }
    public void deposit(double amt) { if (amt > 0) balance += amt; }
}
```

### 6️⃣0️⃣ What is an inner class? 📦
A class **defined inside another class**. It has access to the outer class's members (including private ones) and is used to logically group classes that are only used in one place.

```java
class Outer {
    private int x = 10;
    class Inner { // inner class
        void display() { System.out.println("x = " + x); }
    }
}
Outer.Inner inner = new Outer().new Inner();
```

### 6️⃣1️⃣ What is a static inner class? 🧊
An inner class declared **`static`** — it does **not** have access to the outer class's instance members and doesn't need an outer class instance to be created.

```java
class Outer {
    static class StaticInner {
        void display() { System.out.println("Static inner class"); }
    }
}
Outer.StaticInner obj = new Outer.StaticInner(); // no outer instance needed
```

### 6️⃣2️⃣ Can you create an inner class inside a method? 🎯
Yes — this is called a **local class**. It's only visible within that method and can access effectively final local variables.

```java
void process() {
    final int factor = 2;
    class Multiplier { // local inner class
        int multiply(int x) { return x * factor; }
    }
    Multiplier m = new Multiplier();
    System.out.println(m.multiply(5)); // 10
}
```

### 6️⃣3️⃣ What is an anonymous class? 👻
A class **without a name**, declared and instantiated in a single expression — typically used to override a method or implement an interface on the fly.

```java
Runnable r = new Runnable() {
    @Override
    public void run() {
        System.out.println("Running anonymously");
    }
};
r.run();
```

## 🔐 Modifiers

### 6️⃣4️⃣ What is default class modifier? 📦
When no access modifier is specified for a top-level class, it has **package-private (default)** access — visible only within the same package.

```java
class Helper { } // default access - visible only in same package
```

### 6️⃣5️⃣ What is private access modifier? 🔒
`private` members are accessible **only within the same class**.

```java
class Account {
    private double balance; // accessible only inside Account class
}
```

### 6️⃣6️⃣ What is default or package access modifier? 📮
When **no modifier** is written, the member is accessible only within the **same package**.

```java
class Test {
    int value = 10; // package-private (default)
}
```

### 6️⃣7️⃣ What is protected access modifier? 🛡️
`protected` members are accessible within the **same package** and by **subclasses in other packages**.

```java
class Animal {
    protected void makeSound() { System.out.println("Some sound"); }
}
```

### 6️⃣8️⃣ What is public access modifier? 🌐
`public` members are accessible from **anywhere** — any class, in any package.

```java
public class Utility {
    public static void printHello() { System.out.println("Hello"); }
}
```

### 6️⃣9️⃣ What access types of variables can be accessed from a class in same package? 📋
**public, protected, default,** and even (not) **private** — actually private is NOT accessible even from another class in the same package. So: **public, protected, and default** are accessible; **private is not**.

### 7️⃣0️⃣ What access types of variables can be accessed from a class in different package? 📋
Only **public** members are accessible (assuming the accessing class is unrelated, i.e. not a subclass).

### 7️⃣1️⃣ What access types of variables can be accessed from a sub class in same package? 📋
**public, protected, and default** are accessible (private is not).

### 7️⃣2️⃣ What access types of variables can be accessed from a sub class in different package? 📋
Only **public and protected** are accessible (default and private are not).

### 7️⃣3️⃣ What is the use of a final modifier on a class? 🚫
A `final` class **cannot be extended/inherited**. Used to prevent subclassing (e.g., `String`, `Integer` are final).

```java
final class Constants { }
// class MyConstants extends Constants { } // ❌ compile error
```

### 7️⃣4️⃣ What is the use of a final modifier on a method? 🚫
A `final` method **cannot be overridden** by subclasses.

```java
class Parent {
    final void show() { System.out.println("Cannot override me"); }
}
```

### 7️⃣5️⃣ What is a final variable? 🔏
A `final` variable's value, **once assigned, cannot be changed** — effectively becomes a constant.

```java
final int MAX_VALUE = 100;
// MAX_VALUE = 200; // ❌ compile error
```

### 7️⃣6️⃣ What is a final argument? 📌
A method parameter declared `final` **cannot be reassigned inside the method body**.

```java
void process(final int value) {
    // value = 20; // ❌ compile error
    System.out.println(value);
}
```

### 7️⃣7️⃣ What happens when a variable is marked as volatile? 🌊
`volatile` ensures that a variable's value is **always read from and written to main memory**, not cached in a thread's local CPU cache — guaranteeing **visibility** of changes across threads (but not atomicity).

```java
class SharedFlag {
    private volatile boolean running = true;
    void stop() { running = false; } // visible to all threads immediately
}
```

### 7️⃣8️⃣ What is a static variable? 🧮
A `static` variable belongs to the **class itself**, not to any specific instance — shared across all objects of the class.

```java
class Counter {
    static int count = 0; // shared by all objects
    Counter() { count++; }
}
new Counter(); new Counter();
System.out.println(Counter.count); // 2
```

## 🔁 Conditions & Loops

### 7️⃣9️⃣ Why should you always use blocks around if statement? 🧱
Without `{}`, only the **immediately next statement** belongs to the `if`. This is a common source of bugs when code is later modified (adding a second statement that unintentionally executes unconditionally).

```java
if (x > 0)
    System.out.println("positive");
    System.out.println("this always runs!"); // 🐛 bug - not part of if!

// ✅ Correct with braces
if (x > 0) {
    System.out.println("positive");
    System.out.println("also positive");
}
```

### 8️⃣0️⃣–8️⃣3️⃣ Guess the output examples 🧩
These are typical "trace the code" style questions about `if`/`switch` fall-through behavior. Key rule to remember: **switch cases fall through** unless you add a `break`.

```java
int x = 2;
switch (x) {
    case 1: System.out.println("one");
    case 2: System.out.println("two");   // matches here
    case 3: System.out.println("three"); // 👈 falls through! prints too
    default: System.out.println("default"); // 👈 also prints!
}
// Output: two, three, default (no break statements!)
```

### 8️⃣4️⃣ Should default be the last case in a switch statement? 📍
No — `default` can technically be placed **anywhere** in a switch block, but by **convention** it is placed **last** for readability. Note that placement doesn't affect fall-through behavior (it only executes when no `case` matches, or via fall-through into it).

### 8️⃣5️⃣ Can a switch statement be used around a String? ✅
Yes, since **Java 7**, `switch` supports `String` values.

```java
String day = "MONDAY";
switch (day) {
    case "MONDAY": System.out.println("Start of week"); break;
    case "FRIDAY": System.out.println("Almost weekend"); break;
    default: System.out.println("Midweek");
}
```


### 8️⃣7️⃣ What is an enhanced for loop? ➰
Also called the **for-each loop**, used to iterate over arrays/collections without needing an index variable.

```java
int[] numbers = {1, 2, 3, 4};
for (int num : numbers) {
    System.out.println(num);
}
```

## ⚠️ Exception Handling

### 9️⃣1️⃣ Why is exception handling important? 🚨
It allows a program to **gracefully handle runtime errors** instead of crashing abruptly, separating error-handling code from regular business logic, and allows the application to **recover or fail safely**.

### 9️⃣2️⃣ What design pattern is used to implement exception handling features in most languages? 🎯
The **Chain of Responsibility** pattern — an exception is thrown and passed up the call stack until a suitable `catch` block (handler) is found.

### 9️⃣3️⃣ What is the need for finally block? 🔚
`finally` contains code that **always executes**, whether or not an exception occurs — typically used for **cleanup** (closing files, releasing resources, closing DB connections).

```java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Error: " + e.getMessage());
} finally {
    System.out.println("This always runs - cleanup here");
}
```

### 9️⃣4️⃣ In what scenarios is code in finally not executed? ⛔
- If `System.exit()` is called before reaching `finally`.
- If the **JVM crashes** or is killed forcibly.
- If there's an **infinite loop** or the thread is killed inside `try`/`catch`.
- If a `StackOverflowError` or `OutOfMemoryError` occurs at a critical point.

### 9️⃣5️⃣ Will finally be executed in the program below? 🤔
```java
try {
    System.out.println("try");
    return;
} finally {
    System.out.println("finally"); // ✅ YES, this still runs before the method returns!
}
```
**Yes.** Even with a `return` statement in `try`, `finally` executes before control actually returns to the caller.

### 9️⃣6️⃣ Is try without a catch allowed? ✅
Yes — as long as it has a `finally` block (`try-finally` is valid without `catch`).

```java
try {
    System.out.println("in try");
} finally {
    System.out.println("in finally");
}
```

### 9️⃣7️⃣ Is try without catch and finally allowed? ✅
Yes — but **only** if it's a **try-with-resources** statement (Java 7+), since resource closing acts implicitly like cleanup.

```java
try (Scanner sc = new Scanner(System.in)) {
    // no catch or finally needed
}
```
(A plain `try` block alone with neither `catch` nor `finally` is **not** allowed — it's a compile error.)

### 9️⃣8️⃣ Can you explain the hierarchy of exception handling classes? 🌳
```
Throwable
 ├── Error (serious, unrecoverable — e.g. OutOfMemoryError, StackOverflowError)
 └── Exception
      ├── Checked Exceptions (e.g. IOException, SQLException)
      └── RuntimeException (Unchecked, e.g. NullPointerException, ArithmeticException)
```

### 9️⃣9️⃣ What is the difference between error and exception? ⚖️
| | Error | Exception |
|---|---|---|
| Meaning | Serious problems, usually **unrecoverable** (e.g. JVM issues) | Conditions a program **can catch and handle** |
| Examples | `OutOfMemoryError`, `StackOverflowError` | `IOException`, `NullPointerException` |
| Should you catch it? | Generally no | Yes, when appropriate |

### 1️⃣0️⃣0️⃣ What is the difference between checked exceptions and unchecked exceptions? ✅❌
| | Checked | Unchecked |
|---|---|---|
| Checked at | **Compile-time** | **Runtime** |
| Must handle? | Yes (try-catch or throws) | No (optional) |
| Examples | `IOException`, `SQLException` | `NullPointerException`, `ArithmeticException` |
| Extends | `Exception` (not `RuntimeException`) | `RuntimeException` |

### 1️⃣0️⃣1️⃣ How do you throw an exception from a method? 🎯
Using the **`throw`** keyword with an exception instance.

```java
void validateAge(int age) {
    if (age < 0) {
        throw new IllegalArgumentException("Age cannot be negative");
    }
}
```

### 1️⃣0️⃣2️⃣ What happens when you throw a checked exception from a method? 📜
The method **must declare it** using `throws` in its signature, or the code **won't compile**, unless it's caught within the method itself.

```java
void readFile() throws IOException { // must declare
    throw new IOException("File not found");
}
```

### 1️⃣0️⃣3️⃣ What are the options you have to eliminate compilation errors when handling checked exceptions? 🔧
1. **Catch** the exception using `try-catch`.
2. **Declare** it using `throws` in the method signature (propagate it up).

```java
// Option 1: catch it
void method1() {
    try { readFile(); } catch (IOException e) { e.printStackTrace(); }
}
// Option 2: declare it
void method2() throws IOException { readFile(); }
```

### 1️⃣0️⃣4️⃣ How do you create a custom exception? 🛠️
Extend `Exception` (checked) or `RuntimeException` (unchecked).

```java
class InsufficientBalanceException extends Exception {
    public InsufficientBalanceException(String message) {
        super(message);
    }
}
// usage
throw new InsufficientBalanceException("Not enough funds");
```

### 1️⃣0️⃣5️⃣ How do you handle multiple exception types with same exception handling block? 🧩
Using the **multi-catch** feature (Java 7+) with `|`.

```java
try {
    // risky code
} catch (IOException | SQLException e) {
    System.out.println("Error: " + e.getMessage());
}
```

### 1️⃣0️⃣6️⃣ Can you explain about try with resources? ♻️
Introduced in Java 7, it **automatically closes resources** (that implement `AutoCloseable`) at the end of the try block, eliminating the need for a manual `finally` block to close them.

```java
try (FileReader fr = new FileReader("file.txt")) {
    // use fr
} catch (IOException e) {
    e.printStackTrace();
} // fr.close() called automatically!
```

### 1️⃣0️⃣7️⃣ How does try with resources work? ⚙️
Any resource declared inside `try(...)` must implement `AutoCloseable` (has a `close()` method). At the end of the try block (whether it completes normally or via exception), the JVM **automatically calls `close()`** on each resource, in **reverse order** of declaration.

```java
try (FileReader fr = new FileReader("a.txt");
     BufferedReader br = new BufferedReader(fr)) {
    System.out.println(br.readLine());
} // br.close() called first, then fr.close()
```

### 1️⃣0️⃣8️⃣ Can you explain a few exception handling best practices? ✅
- Catch **specific exceptions**, not generic `Exception` or `Throwable`.
- **Don't swallow** exceptions silently (avoid empty catch blocks).
- Use **try-with-resources** for closeable resources.
- Include **meaningful messages** when throwing exceptions.
- Don't use exceptions for **normal control flow**.
- **Log** exceptions properly instead of just printing stack traces.

```java
try {
    process();
} catch (SpecificException e) { // ✅ specific
    logger.error("Processing failed", e); // ✅ logged properly
}
```

### 1️⃣0️⃣9️⃣ What are the default values in an array? 0️⃣

```java
int[] arr = new int[3];
```

```java
int[] numbers = {10, 20, 30};
```

### 1️⃣1️⃣1️⃣ How do you print the content of an array? 🖨️
Use `Arrays.toString()` (for 1D) or `Arrays.deepToString()` (for multi-dimensional arrays) — printing the array directly gives an unreadable hashcode.

```java
int[] arr = {1, 2, 3};
System.out.println(arr); // [I@1540e19d  ❌ unreadable
```

Use `Arrays.equals()` for 1D arrays (compares content, not reference).

```java
int[] a = {1, 2, 3};
int[] b = {1, 2, 3};
System.out.println(a == b);              // false (different objects)
System.out.println(Arrays.equals(a, b)); // true (same content)
```

### 1️⃣1️⃣3️⃣ What is an enum? 🎯
A special type used to define a **fixed set of named constants**.

```java
enum Day { MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY }
Day today = Day.MONDAY;
```

### 1️⃣1️⃣4️⃣ Can you use a switch statement around an enum? ✅
Yes.

```java
Day day = Day.MONDAY;
switch (day) {
    case MONDAY: System.out.println("Start of work week"); break;
    case FRIDAY: System.out.println("Almost weekend"); break;
    default: System.out.println("Regular day");
}
```

### 1️⃣1️⃣5️⃣ What are variable arguments or varargs? 📥
Allows a method to accept **zero or more arguments** of the same type, treated internally as an array. Denoted with `...`.

```java
static int sum(int... numbers) {
    int total = 0;
    for (int n : numbers) total += n;
    return total;
}
sum(1, 2, 3); // 6
sum();        // 0
```

### 1️⃣1️⃣6️⃣ What are asserts used for? ✔️
`assert` is used to verify **assumptions during development/testing** — checks a boolean condition and throws `AssertionError` if false. Disabled by default at runtime (must enable with `-ea` flag).

```java
int age = -5;
assert age >= 0 : "Age cannot be negative"; // throws AssertionError if run with -ea
```

### 1️⃣1️⃣7️⃣ When should asserts be used? 🎯
- To check **internal invariants** and assumptions during development/testing.
- **Not** for validating user input or public API arguments (use exceptions instead, since asserts can be disabled in production).

### 1️⃣1️⃣8️⃣ What is garbage collection? ♻️
The automatic process by which the **JVM reclaims memory** occupied by objects that are **no longer reachable/referenced** by the program, freeing the developer from manual memory management.

### 1️⃣1️⃣9️⃣ Can you explain garbage collection with an example? 🗑️
```java
class Person { }
Person p = new Person(); // object created, referenced by p
p = null; // object no longer referenced -> eligible for garbage collection
System.gc(); // request GC (not guaranteed to run immediately)
```

### 1️⃣2️⃣0️⃣ When is garbage collection run? ⏱️
It runs **automatically** at JVM's discretion, typically when available memory becomes low. You can **request** it with `System.gc()`, but the JVM is **not obligated** to run it immediately or at all.

### 1️⃣2️⃣1️⃣ What are best practices on garbage collection? 📋
- Set unused object references to `null` when appropriate.
- Avoid **memory leaks** (e.g., unclosed resources, listeners not deregistered).
- Use **try-with-resources** for closing streams/connections.
- Avoid excessive object creation in loops.
- Understand generational GC (Young/Old generation) for tuning large apps.

### 1️⃣2️⃣2️⃣ What are initialization blocks? 🧱
Blocks of code (`{ }`) inside a class used to **initialize instance or static fields**, executed **before the constructor** runs (for instance blocks).

```java
class Test {
    { System.out.println("Instance initializer block"); } // runs before constructor
    Test() { System.out.println("Constructor"); }
}
```

### 1️⃣2️⃣3️⃣ What is a static initializer? 🧊
A block marked `static` that runs **once**, when the class is **first loaded** by the JVM — used to initialize static fields.

```java
class Config {
    static int MAX;
    static {
        MAX = 100; // runs once when class loads
        System.out.println("Static block executed");
    }
}
```

### 1️⃣2️⃣4️⃣ What is an instance initializer block? 🎬
A non-static block that runs **every time an object is created**, right before the constructor body (after `super()` call).

```java
class Test {
    int x;
    { x = 10; } // instance initializer - runs on every "new Test()"
    Test() { System.out.println("x = " + x); }
}
```

### 1️⃣2️⃣5️⃣ What is tokenizing? ✂️
Tokenizing is the process of **breaking a string into smaller pieces (tokens)** based on a delimiter, commonly used for parsing input.

### 1️⃣2️⃣6️⃣ Can you give an example of tokenizing? 📝
```java
String sentence = "Java is fun";
StringTokenizer st = new StringTokenizer(sentence, " ");
while (st.hasMoreTokens()) {
    System.out.println(st.nextToken()); // Java, is, fun
}
// Modern alternative:
String[] words = sentence.split(" ");
```

### 1️⃣2️⃣7️⃣ What is serialization? 💾
Serialization is the process of **converting an object into a byte stream** so it can be saved to a file, sent over a network, or stored in a database.

### 1️⃣2️⃣8️⃣ How do you serialize an object using serializable interface? 🔧
Implement the marker interface `Serializable`, then use `ObjectOutputStream`.

```java
class Person implements Serializable {
    String name;
    Person(String name) { this.name = name; }
}
ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("person.ser"));
oos.writeObject(new Person("Alice"));
oos.close();
```

### 1️⃣2️⃣9️⃣ How do you de-serialize in Java? 📂
Use `ObjectInputStream` to read the object back.

```java
ObjectInputStream ois = new ObjectInputStream(new FileInputStream("person.ser"));
Person p = (Person) ois.readObject();
ois.close();
```

### 1️⃣3️⃣0️⃣ What do you do if only parts of the object have to be serialized? 🎯
Mark the fields you **don't** want serialized as **`transient`**.

```java
class User implements Serializable {
    String username;
    transient String password; // won't be serialized
}
```

### 1️⃣3️⃣1️⃣ How do you serialize a hierarchy of objects? 🌳
If a superclass implements `Serializable`, all subclasses are automatically serializable too. If a superclass does **not** implement `Serializable`, its fields are **not serialized** (and it must have a no-arg constructor for deserialization to work correctly).

```java
class Animal implements Serializable { String type; }
class Dog extends Animal { String breed; } // Dog is Serializable too
```

### 1️⃣3️⃣2️⃣ Are the constructors in an object invoked when it is de-serialized? ❌
**No** — deserialization **does not call the class's constructor**. The object is recreated directly from the byte stream using reflection-based mechanisms.

### 1️⃣3️⃣3️⃣ Are the values of static variables stored when an object is serialized? ❌
**No** — `static` variables belong to the **class**, not the object, so they are **not part of an object's serialized state**.

## 📊 Collections

### 1️⃣3️⃣4️⃣ Why do we need collections in Java? 🎯
Collections provide **ready-made, reusable data structures** (lists, sets, maps, queues) with built-in algorithms, replacing the need for arrays with fixed size, and offering dynamic resizing, sorting, searching, and more.

### 1️⃣3️⃣5️⃣ What are the important interfaces in the collection hierarchy? 🌳
```
Iterable
 └── Collection
      ├── List (ArrayList, LinkedList, Vector)
      ├── Set (HashSet, LinkedHashSet, TreeSet)
      └── Queue (PriorityQueue, Deque)
Map (separate hierarchy - not a Collection)
 ├── HashMap
 ├── LinkedHashMap
 └── TreeMap
```

### 1️⃣3️⃣6️⃣ What are the important methods declared in the collection interface? 🔧
```java
add(E e), remove(Object o), size(), isEmpty(), contains(Object o),
iterator(), clear(), addAll(Collection c), removeAll(Collection c),
retainAll(Collection c), toArray()
```

### 1️⃣3️⃣7️⃣ Can you explain briefly about the List interface? 📋
`List` is an **ordered collection** that allows **duplicate elements** and provides positional (index-based) access.

```java
List<String> list = new ArrayList<>();
list.add("A"); list.add("B"); list.add("A"); // duplicates allowed
System.out.println(list.get(0)); // "A"
```

### 1️⃣3️⃣8️⃣ Explain about ArrayList with an example? 📝
`ArrayList` is a **resizable array** implementation of `List` — fast random access (`O(1)` get), slower insert/delete in the middle (`O(n)`).

```java

fruits.add("Apple");
fruits.add("Banana");
```

### 1️⃣3️⃣9️⃣ Can an ArrayList have duplicate elements? ✅
Yes, `ArrayList` allows duplicates (unlike `Set`).

```java
List<Integer> list = new ArrayList<>();
list.add(1); list.add(1); // duplicates allowed
System.out.println(list); // [1, 1]
```

### 1️⃣4️⃣0️⃣ How do you iterate around an ArrayList using iterator? 🔄

```java
List<String> list = Arrays.asList("A", "B", "C");
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    System.out.println(it.next());
```

### 1️⃣4️⃣1️⃣ How do you sort an ArrayList? 🔀
```java
List<Integer> numbers = new ArrayList<>(Arrays.asList(5, 2, 8, 1));
Collections.sort(numbers); // natural order
System.out.println(numbers); // [1, 2, 5, 8]
```

### 1️⃣4️⃣2️⃣ How do you sort elements in an ArrayList using comparable interface? 📐
Implement `Comparable<T>` and override `compareTo()` in the class itself (defines **natural ordering**).

```java
class Employee implements Comparable<Employee> {
    int age;
    Employee(int age) { this.age = age; }
    public int compareTo(Employee other) { return this.age - other.age; }
}
List<Employee> list = new ArrayList<>();
Collections.sort(list); // uses compareTo()
```

### 1️⃣4️⃣3️⃣ How do you sort elements in an ArrayList using comparator interface? 🎛️
Use `Comparator<T>` for **custom, external sorting logic** (useful when you need multiple sort orders).

```java
List<Employee> list = new ArrayList<>();

list.sort(Comparator.comparingInt((Employee e) -> e.age).reversed()); // descending
```

### 1️⃣4️⃣4️⃣ What is vector class? How is it different from an ArrayList? 🆚
`Vector` is a **legacy, synchronized (thread-safe)** dynamic array, similar to `ArrayList` but slower due to synchronization overhead. `ArrayList` is **not** synchronized.

| Performance | Slower | Faster |

### 1️⃣4️⃣5️⃣ What is linkedList? What interfaces does it implement? How is it different from an ArrayList? 🔗
`LinkedList` is a **doubly-linked list** implementation. It implements `List` and `Deque`. Unlike `ArrayList` (backed by an array), it has **fast insertion/deletion** (`O(1)` at ends) but **slower random access** (`O(n)`).

```java
LinkedList<String> list = new LinkedList<>();
list.addFirst("A");
list.addLast("B");
```

### 1️⃣4️⃣6️⃣ Can you briefly explain about the Set interface? 🎯
`Set` is a collection that **does not allow duplicate elements** and generally does not guarantee order (except specific implementations).

```java
Set<String> set = new HashSet<>();
set.add("A"); set.add("A"); // duplicate ignored
System.out.println(set.size()); // 1
```

### 1️⃣4️⃣7️⃣ What are the important interfaces related to the Set interface? 📜
- `Set` (base interface)
- `SortedSet` (maintains sorted order)
- `NavigableSet` (extends SortedSet with navigation methods like `floor()`, `ceiling()`)

### 1️⃣4️⃣8️⃣ What is the difference between Set and sortedSet interfaces? 🆚
`Set` has **no ordering guarantee**; `SortedSet` maintains elements in **ascending (natural or custom comparator) order**.

```java
Set<Integer> s = new HashSet<>(Arrays.asList(3, 1, 2));      // order not guaranteed
SortedSet<Integer> ss = new TreeSet<>(Arrays.asList(3, 1, 2)); // [1, 2, 3] - sorted
```

### 1️⃣4️⃣9️⃣ Can you give examples of classes that implement the Set interface? 📦
`HashSet`, `LinkedHashSet`, `TreeSet`.

### 1️⃣5️⃣0️⃣ What is a HashSet? #️⃣
Uses a **hash table** internally — offers `O(1)` average time for add/remove/contains, but **no ordering guarantee**.

```java
Set<String> set = new HashSet<>();
set.add("Banana"); set.add("Apple");
System.out.println(set); // order not guaranteed, e.g. [Apple, Banana]
```

### 1️⃣5️⃣1️⃣ What is a linkedHashSet? How is it different from a HashSet? 🔗
`LinkedHashSet` maintains **insertion order** (using a linked list internally alongside the hash table), unlike `HashSet` which has no ordering.

```java
Set<String> set = new LinkedHashSet<>();
set.add("Banana"); set.add("Apple");

```

### 1️⃣5️⃣2️⃣ What is a TreeSet? How is it different from a HashSet? 🌲
`TreeSet` stores elements in **sorted (ascending) order** using a Red-Black tree, offering `O(log n)` operations — unlike `HashSet`'s `O(1)` but unordered nature.

```java
Set<Integer> set = new TreeSet<>(Arrays.asList(5, 1, 3));
System.out.println(set); // [1, 3, 5] - sorted
```

### 1️⃣5️⃣3️⃣ Can you give examples of implementations of navigableSet? 🧭
`TreeSet` is the primary implementation of `NavigableSet`, offering methods like `higher()`, `lower()`, `ceiling()`, `floor()`, `pollFirst()`, `pollLast()`.

```java

System.out.println(set.higher(15)); // 20
System.out.println(set.lower(15));  // 10
```

### 1️⃣5️⃣4️⃣ Explain briefly about Queue interface? 🎫
`Queue` represents a collection designed for **holding elements before processing**, typically **FIFO (First-In-First-Out)**.

```java
Queue<Integer> queue = new LinkedList<>();
```

### 1️⃣5️⃣5️⃣ What are the important interfaces related to the Queue interface? 📜
`Queue`, `Deque` (double-ended queue), `BlockingQueue` (for concurrent producer-consumer scenarios).

### 1️⃣5️⃣6️⃣ Explain about the Deque interface? ↔️
`Deque` ("Double Ended Queue") allows insertion/removal from **both ends** — can be used as a Queue (FIFO) or a Stack (LIFO).

```java
Deque<Integer> deque = new ArrayDeque<>();
```

### 1️⃣5️⃣7️⃣ Explain the BlockingQueue interface? 🚦
A thread-safe `Queue` that **blocks** the calling thread when trying to `add`/`take` if the queue is full/empty — used heavily in **producer-consumer** patterns.

```java
BlockingQueue<Integer> queue = new LinkedBlockingQueue<>(10);

```

### 1️⃣5️⃣8️⃣ What is a priorityQueue? 🥇
A queue where elements are ordered according to their **natural ordering or a custom comparator**, so the **smallest (or highest priority)** element is always dequeued first.

```java
PriorityQueue<Integer> pq = new PriorityQueue<>();
pq.add(5); pq.add(1); pq.add(3);
System.out.println(pq.poll()); // 1 (smallest first)
```

`ArrayBlockingQueue`, `LinkedBlockingQueue`, `PriorityBlockingQueue`, `SynchronousQueue`.

### 1️⃣6️⃣0️⃣ Can you briefly explain about the Map interface? 🗺️

## ⚡ Advanced Collections

### 1️⃣6️⃣7️⃣ What is the difference between synchronized and concurrent collections in Java? 🆚
- **Synchronized collections** (e.g., `Collections.synchronizedList()`, `Vector`, `Hashtable`) lock the **entire collection** for every operation — simple but can cause **contention/bottlenecks**.
- **Concurrent collections** (`java.util.concurrent` package, e.g., `ConcurrentHashMap`) use **finer-grained locking** (like segment/bucket-level locks) or lock-free algorithms, offering **much better performance** under high concurrency.

```java
List<Integer> syncList = Collections.synchronizedList(new ArrayList<>()); // whole-list lock
Map<String, Integer> concurrentMap = new ConcurrentHashMap<>(); // fine-grained locking
```

### 1️⃣6️⃣8️⃣ Explain about the new concurrent collections in Java? 🚀
Introduced in `java.util.concurrent`:
- `ConcurrentHashMap` — thread-safe map with high concurrency
- `CopyOnWriteArrayList` / `CopyOnWriteArraySet` — thread-safe list/set for read-heavy scenarios
- `BlockingQueue` implementations (`LinkedBlockingQueue`, `ArrayBlockingQueue`) — for producer-consumer patterns
- `ConcurrentLinkedQueue` — lock-free queue

```java
ConcurrentHashMap<String, Integer> map = new ConcurrentHashMap<>();
map.put("count", 1); // thread-safe without full locking
```

### 1️⃣6️⃣9️⃣ Explain about copyonwrite concurrent collections approach? 📝
`CopyOnWriteArrayList`/`Set` create a **new copy of the underlying array** every time a **write** (add/remove) operation happens, while **reads** never need locking (they read the current stable snapshot). Ideal for scenarios with **many reads and very few writes**.

```java
CopyOnWriteArrayList<String> list = new CopyOnWriteArrayList<>();
list.add("A"); // creates a new internal array copy
// Iteration is safe even if another thread modifies the list concurrently
for (String s : list) { System.out.println(s); }
```

### 1️⃣7️⃣0️⃣ What is compareandswap approach? ⚖️
**CAS (Compare-And-Swap)** is a **lock-free, atomic** technique: it compares a memory location's current value to an expected value, and **only if they match**, swaps in a new value — all in one atomic hardware operation. Used internally by classes like `AtomicInteger`.

```java
AtomicInteger counter = new AtomicInteger(0);
counter.compareAndSet(0, 1); // atomically sets to 1 only if current value is 0
```

### 1️⃣7️⃣1️⃣ What is a lock? How is it different from using synchronized approach? 🔓
`Lock` (from `java.util.concurrent.locks`, e.g., `ReentrantLock`) offers more **flexible locking** than the `synchronized` keyword: supports **tryLock()** (non-blocking attempt), **timed locking**, **interruptible locking**, and **fairness policies** — while `synchronized` is simpler but more rigid (automatically released, block-scoped only).

```java
Lock lock = new ReentrantLock();
lock.lock();
try {
    // critical section
} finally {
    lock.unlock(); // must manually unlock
}
```

### 1️⃣7️⃣2️⃣ What is initial capacity of a Java collection? 📏
The **number of buckets/slots** allocated when a hash-based collection (like `HashMap`/`HashSet`) is first created, before any resizing happens. Default is usually **16**.

```java
Map<String, Integer> map = new HashMap<>(32); // initial capacity of 32
```

### 1️⃣7️⃣3️⃣ What is load factor? 📊
A measure of **how full a hash table is allowed to get** before it's **automatically resized (rehashed)**. Default load factor is **0.75** (i.e., resize when 75% full), balancing memory usage vs. performance.

```java
Map<String, Integer> map = new HashMap<>(16, 0.75f); // capacity=16, load factor=0.75
// resizes to 32 once it has more than 12 entries (16 * 0.75)
```

### 1️⃣7️⃣4️⃣ When does a Java collection throw UnsupportedOperationException? 🚫
When you try to **modify an immutable/fixed-size collection**, e.g., one created via `List.of()`, `Collections.unmodifiableList()`, or `Arrays.asList()`.

```java
List<Integer> immutable = List.of(1, 2, 3);
immutable.add(4); // ❌ throws UnsupportedOperationException
```

### 1️⃣7️⃣5️⃣ What is difference between fail-safe and fail-fast iterators? 🆚
- **Fail-fast** (e.g., `ArrayList`, `HashMap` iterators): throw `ConcurrentModificationException` if the collection is **structurally modified** while iterating (outside the iterator's own methods).
- **Fail-safe** (e.g., `CopyOnWriteArrayList`, `ConcurrentHashMap` iterators): operate on a **cloned/snapshot copy**, so they don't throw exceptions even if the original collection is modified during iteration.

```java
List<Integer> list = new ArrayList<>(Arrays.asList(1, 2, 3));
for (Integer i : list) {
    list.add(4); // ❌ throws ConcurrentModificationException (fail-fast)
}
```

### 1️⃣7️⃣6️⃣ What are atomic operations in Java? ⚛️
Operations that **complete in a single, indivisible step**, without interference from other threads — provided by the `java.util.concurrent.atomic` package (`AtomicInteger`, `AtomicLong`, `AtomicBoolean`, `AtomicReference`).

```java
AtomicInteger counter = new AtomicInteger(0);
counter.incrementAndGet(); // atomic, thread-safe increment — no synchronized needed!
```

### 1️⃣7️⃣7️⃣ What is BlockingQueue in Java? 🚦
(See #157) A thread-safe queue that **blocks** the producer thread when full (on `put()`) and the consumer thread when empty (on `take()`) — ideal for **producer-consumer** designs.

```java
BlockingQueue<String> queue = new ArrayBlockingQueue<>(5);
// Producer thread
queue.put("task1");
// Consumer thread
String task = queue.take();
```

## 🧬 Generics

### 1️⃣7️⃣8️⃣ What are Generics? 🧪
Generics allow classes, interfaces, and methods to operate on **types specified as parameters**, providing **compile-time type safety** without needing to cast.

```java
List<String> list = new ArrayList<>(); // only Strings allowed
list.add("Hello");
String s = list.get(0); // no cast needed!
```

### 1️⃣7️⃣9️⃣ Why do we need Generics? Can you give an example of how Generics make a program more flexible? 💪
Without generics, collections stored `Object`, requiring manual casting and risking `ClassCastException` at runtime. Generics catch type errors at **compile-time** and eliminate the need for casting.

```java
// Without generics (old way) ❌
List list = new ArrayList();
list.add("Hello");
list.add(123); // no error! but...
String s = (String) list.get(1); // 💥 ClassCastException at runtime

// With generics ✅
List<String> list2 = new ArrayList<>();
list2.add("Hello");
// list2.add(123); // ❌ compile-time error - caught early!
```

### 1️⃣8️⃣0️⃣ How do you declare a generic class? 🏗️
```java
class Box<T> {
    private T item;
    void set(T item) { this.item = item; }
    T get() { return item; }
}
Box<String> stringBox = new Box<>();
stringBox.set("Hello");
```

### 1️⃣8️⃣1️⃣ What are the restrictions in using generic type that is declared in a class declaration? ⚠️
- Cannot create instances of the generic type: `new T()` ❌
- Cannot create arrays of the generic type: `new T[10]` ❌
- Cannot use primitives as type parameters: `Box<int>` ❌ (must use `Box<Integer>`)
- Cannot use `static` fields of type `T` ❌
- Cannot use `instanceof` with generic types directly (due to type erasure)

### 1️⃣8️⃣2️⃣ How can we restrict Generics to a subclass of a particular class? ⬇️
Using an **upper-bounded wildcard**: `<T extends SomeClass>`.

```java
class Box<T extends Number> { // T must be Number or its subclass
    T value;
}
Box<Integer> b1 = new Box<>(); // ✅ OK
// Box<String> b2 = new Box<>(); // ❌ compile error
```

### 1️⃣8️⃣3️⃣ How can we restrict Generics to a super class of a particular class? ⬆️
Using a **lower-bounded wildcard**: `<? super SomeClass>`.

```java
void addNumbers(List<? super Integer> list) { // list of Integer or its superclass
    list.add(10);
}
List<Number> numbers = new ArrayList<>();
addNumbers(numbers); // ✅ works, Number is a superclass of Integer
```

### 1️⃣8️⃣4️⃣ Can you give an example of a generic method? 🔧
```java
static <T> void printArray(T[] array) {
    for (T item : array) {
        System.out.println(item);
    }
}
Integer[] intArray = {1, 2, 3};
String[] strArray = {"A", "B"};
printArray(intArray); // works with any type
printArray(strArray);
```

## 🧵 Multi-threading

### 1️⃣8️⃣5️⃣ What is the need for threads in Java? 🎯
Threads allow a program to perform **multiple tasks concurrently**, improving **responsiveness** (e.g., UI stays responsive while background work happens) and **performance** by utilizing **multi-core CPUs**.

### 1️⃣8️⃣6️⃣ How do you create a thread? 🧵
Two ways: **extending `Thread`** class or **implementing `Runnable`** interface.

```java
// Way 1: extend Thread
class MyThread extends Thread {
    public void run() { System.out.println("Thread running"); }
}
// Way 2: implement Runnable (preferred)
class MyTask implements Runnable {
    public void run() { System.out.println("Task running"); }
}
```

### 1️⃣8️⃣7️⃣ How do you create a thread by extending thread class? 🏗️
```java
class MyThread extends Thread {
    public void run() {
        System.out.println("Running in: " + Thread.currentThread().getName());
    }
}
MyThread t = new MyThread();
t.start(); // starts new thread, calls run()
```

### 1️⃣8️⃣8️⃣ How do you create a thread by implementing runnable interface? 🎯
```java
class MyTask implements Runnable {
    public void run() {
        System.out.println("Running task");
    }
}
Thread t = new Thread(new MyTask());
t.start();
```
💡 **Preferred approach** since Java doesn't support multiple inheritance — implementing `Runnable` leaves the class free to extend another class.

### 1️⃣8️⃣9️⃣ How do you run a thread in Java? ▶️
Call **`start()`**, NOT `run()` directly! `start()` creates a new call stack and actually runs concurrently; calling `run()` directly just executes it like a normal method on the current thread.

```java
Thread t = new Thread(() -> System.out.println("Hello from thread"));
t.start(); // ✅ correct - runs in new thread
// t.run(); // ❌ wrong - runs on the CURRENT thread, no concurrency
```

### 1️⃣9️⃣0️⃣ What are the different states of a thread? 🔄
```
NEW → RUNNABLE → RUNNING → (BLOCKED / WAITING / TIMED_WAITING) → TERMINATED
```
- **NEW**: created but not started
- **RUNNABLE**: ready to run / running
- **BLOCKED**: waiting for a lock
- **WAITING/TIMED_WAITING**: waiting indefinitely/for a time period
- **TERMINATED**: finished execution

### 1️⃣9️⃣1️⃣ What is priority of a thread? How do you change the priority of a thread? ⭐
Thread priority (1-10, default 5) is a **hint** to the scheduler about relative importance — not a guarantee of execution order.

```java
Thread t = new Thread(() -> System.out.println("task"));
t.setPriority(Thread.MAX_PRIORITY); // 10
```

### 1️⃣9️⃣2️⃣ What is executorservice? 🏭
A **high-level framework** (`java.util.concurrent.ExecutorService`) for managing a **pool of threads**, submitting tasks for execution, and handling their lifecycle — avoids manually creating/managing `Thread` objects.

### 1️⃣9️⃣3️⃣ Can you give an example for executorservice? 📝
```java
ExecutorService executor = Executors.newFixedThreadPool(3);
executor.submit(() -> System.out.println("Task executed"));
executor.shutdown(); // gracefully shuts down after tasks complete
```

### 1️⃣9️⃣4️⃣ Explain different ways of creating executor services. 🏗️
```java
Executors.newFixedThreadPool(5);      // fixed number of threads
Executors.newCachedThreadPool();       // creates threads as needed, reuses idle ones
Executors.newSingleThreadExecutor();   // single worker thread
Executors.newScheduledThreadPool(3);   // for scheduled/periodic tasks
```

### 1️⃣9️⃣5️⃣ How do you check whether an executionservice task executed successfully? ✅
Use the **`Future`** object returned by `submit()`.

```java
ExecutorService executor = Executors.newSingleThreadExecutor();
Future<?> future = executor.submit(() -> System.out.println("Task"));
future.get(); // blocks until task completes; throws exception if task failed
System.out.println(future.isDone()); // true once completed
```

### 1️⃣9️⃣6️⃣ What is callable? How do you execute a callable from executionservice? 📞
`Callable<V>` is like `Runnable` but **can return a value** and **throw checked exceptions**.

```java
Callable<Integer> task = () -> {
    return 10 + 20;
};
ExecutorService executor = Executors.newSingleThreadExecutor();
Future<Integer> future = executor.submit(task);
System.out.println(future.get()); // 30
```

### 1️⃣9️⃣7️⃣ What is synchronization of threads? 🔒
Synchronization ensures that **only one thread at a time** can access a critical section of code / shared resource, preventing **race conditions**.

```java
class Counter {
    private int count = 0;
    synchronized void increment() { count++; } // only one thread at a time
}
```

### 1️⃣9️⃣8️⃣ Can you give an example of a synchronized block? 🔐
A synchronized **block** locks only a specific section (more granular than a synchronized method), using any object as the lock.

```java
class BankAccount {
    private double balance;
    private final Object lock = new Object();
    void withdraw(double amount) {
        synchronized (lock) { // only this block is locked
            balance -= amount;
        }
    }
}
```

### 1️⃣9️⃣9️⃣ Can a static method be synchronized? ✅
Yes — a `synchronized static` method locks on the **Class object** (`ClassName.class`), not on an instance.

```java
class Counter {
    static int count = 0;
    static synchronized void increment() { count++; } // locks Counter.class
}
```

### 2️⃣0️⃣0️⃣ What is the use of join method in threads? 🤝
`join()` makes the **calling thread wait** until the specified thread **finishes execution**.

```java
Thread t = new Thread(() -> System.out.println("Task running"));
t.start();
t.join(); // main thread waits here until t finishes
System.out.println("t has finished");
```

### 2️⃣0️⃣1️⃣ Describe a few other important methods in threads? 📋
```java
Thread.sleep(1000);      // pauses current thread for 1000ms
thread.interrupt();      // interrupts a thread
Thread.currentThread();  // returns reference to currently executing thread
thread.isAlive();        // checks if thread is still running
thread.setDaemon(true);  // marks thread as daemon (background) thread
```

### 2️⃣0️⃣2️⃣ What is a deadlock? 🔒🔒
A situation where **two or more threads are blocked forever**, each waiting for a resource held by the other — no thread can proceed.

```java
// Thread 1: locks resourceA, then waits for resourceB
// Thread 2: locks resourceB, then waits for resourceA
// 💀 Neither can proceed -> DEADLOCK
synchronized (resourceA) {
    synchronized (resourceB) { /* ... */ }
}
```

### 2️⃣0️⃣3️⃣ What are the important methods in Java for inter-thread communication? 💬
`wait()`, `notify()`, `notifyAll()` — all defined in `Object` class, used within `synchronized` blocks.

### 2️⃣0️⃣4️⃣ What is the use of wait method? ⏸️
`wait()` causes the current thread to **release the lock and pause**, until another thread calls `notify()`/`notifyAll()` on the same object.

```java
synchronized (lockObj) {
    while (!conditionMet) {
        lockObj.wait(); // releases lock, waits
    }
}
```

### 2️⃣0️⃣5️⃣ What is the use of notify method? 📢
`notify()` **wakes up one** waiting thread (chosen arbitrarily) that is waiting on the same object's monitor.

```java
synchronized (lockObj) {
    conditionMet = true;
    lockObj.notify(); // wakes up one waiting thread
}
```

### 2️⃣0️⃣6️⃣ What is the use of notifyall method? 📣
`notifyAll()` wakes up **all** threads waiting on that object's monitor (they then compete to reacquire the lock).

```java
synchronized (lockObj) {
    conditionMet = true;
    lockObj.notifyAll(); // wakes up ALL waiting threads
}
```

### 2️⃣0️⃣7️⃣ Can you write a synchronized program with wait and notify methods? 📝
```java
class SharedResource {
    private boolean available = false;

    synchronized void produce() {
        available = true;
        System.out.println("Produced item");
        notify(); // wake up consumer
    }

    synchronized void consume() throws InterruptedException {
        while (!available) {
            wait(); // wait until producer notifies
        }
        System.out.println("Consumed item");
        available = false;
    }
}
```

## λ Functional Programming - Lambda expressions and Streams

### 2️⃣0️⃣8️⃣ What is functional programming? 🎯
A programming paradigm where computation is treated as the **evaluation of functions**, favoring **immutability**, avoiding **side effects**, and treating **functions as first-class citizens** (can be passed as arguments, returned from other functions). Java added functional programming support via **lambdas and Streams** in Java 8.

### 2️⃣0️⃣9️⃣ Can you give an example of functional programming? 📝
```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
int sum = numbers.stream()
                  .filter(n -> n % 2 == 0)  // functional style
                  .mapToInt(Integer::intValue)
                  .sum();
System.out.println(sum); // 6 (2+4)
```

### 2️⃣1️⃣0️⃣ What is a stream? 🌊
A `Stream` represents a **sequence of elements** supporting functional-style operations (filter, map, reduce, etc.) that can be chained together — streams **don't store data**, they process data from a source (collection, array).

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.stream().forEach(System.out::println);
```

### 2️⃣1️⃣1️⃣ Explain about streams with an example? What are intermediate operations in streams? 🔗
**Intermediate operations** return a new Stream and are **lazy** (not executed until a terminal operation is invoked) — e.g., `filter()`, `map()`, `sorted()`, `distinct()`, `limit()`.

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "Dan");
List<String> result = names.stream()
    .filter(n -> n.length() > 3)   // intermediate
    .map(String::toUpperCase)      // intermediate
    .sorted()                      // intermediate
    .collect(Collectors.toList()); // terminal
System.out.println(result); // [ALICE, CHARLIE]
```

### 2️⃣1️⃣2️⃣ What are terminal operations in streams? 🏁
**Terminal operations** produce a **result or side-effect** and **trigger** the execution of the stream pipeline — e.g., `collect()`, `forEach()`, `count()`, `reduce()`, `sum()`, `anyMatch()`. Once called, the stream **cannot be reused**.

```java
long count = names.stream().filter(n -> n.startsWith("A")).count(); // terminal
Optional<String> first = names.stream().findFirst(); // terminal
```

### 2️⃣1️⃣3️⃣ What are method references? 🎯
A **shorthand syntax** for a lambda expression that simply calls an **existing method**. Uses `::`.

```java
// Lambda
names.forEach(n -> System.out.println(n));
// Method reference (equivalent, cleaner)
names.forEach(System.out::println);

// Types of method references:
String::toUpperCase       // 1. reference to instance method of a particular type
System.out::println       // 2. reference to instance method of a particular object
Integer::parseInt         // 3. reference to a static method
ArrayList::new             // 4. reference to a constructor
```

### 2️⃣1️⃣4️⃣ What are lambda expressions? λ
A **concise way to represent an anonymous function** — implementing a functional interface's single abstract method inline, without a full class definition.

```java
// Traditional anonymous class
Runnable r1 = new Runnable() {
    public void run() { System.out.println("Running"); }
};
// Lambda expression - much shorter!
Runnable r2 = () -> System.out.println("Running");
```

### 2️⃣1️⃣5️⃣ Can you give an example of lambda expression? 📝
```java
// Lambda with parameters
Comparator<Integer> comp = (a, b) -> a - b;

// Lambda used with a Stream
List<Integer> numbers = Arrays.asList(5, 3, 1, 4);
numbers.sort((a, b) -> a - b); // sorts ascending using lambda

// Lambda assigned to a custom functional interface
interface Greeting { void greet(String name); }
Greeting g = name -> System.out.println("Hello, " + name);
g.greet("Alice"); // "Hello, Alice"
```

### 2️⃣1️⃣6️⃣ Can you explain the relationship between lambda expression and functional interfaces? 🔗
A **lambda expression can only be used where a functional interface is expected**. A **functional interface** is an interface with **exactly one abstract method** (can have default/static methods too), often annotated with `@FunctionalInterface`. The lambda provides the implementation for that single abstract method.

```java
@FunctionalInterface
interface Calculator {
    int calculate(int a, int b); // exactly one abstract method
}
Calculator add = (a, b) -> a + b; // lambda implements calculate()
System.out.println(add.calculate(3, 4)); // 7
```

### 2️⃣1️⃣7️⃣ What is a predicate? ❓
`Predicate<T>` is a built-in functional interface representing a **boolean-valued function** of one argument — commonly used for filtering.

```java
Predicate<Integer> isEven = n -> n % 2 == 0;
System.out.println(isEven.test(4)); // true
List<Integer> nums = Arrays.asList(1, 2, 3, 4);
nums.stream().filter(isEven).forEach(System.out::println); // 2, 4
```

### 2️⃣1️⃣8️⃣ What is the functional interface - function? 🔄
`Function<T, R>` represents a function that takes an argument of type `T` and **returns** a result of type `R`. Has a `apply()` method.

```java
Function<String, Integer> lengthFunction = s -> s.length();
System.out.println(lengthFunction.apply("Hello")); // 5

Function<Integer, Integer> square = x -> x * x;
Function<Integer, Integer> addOne = x -> x + 1;
System.out.println(square.andThen(addOne).apply(3)); // 3*3=9, then +1 = 10
```

### 2️⃣1️⃣9️⃣ What is a consumer? 🍽️
`Consumer<T>` represents an operation that takes an argument and **returns nothing (void)** — typically used to perform an action, like printing.

```java
Consumer<String> printer = s -> System.out.println("Value: " + s);
printer.accept("Hello"); // Value: Hello
List.of("A", "B").forEach(printer); // uses Consumer internally
```

### 2️⃣2️⃣0️⃣ Can you give examples of functional interfaces with multiple arguments? 🔢
```java
BiFunction<Integer, Integer, Integer> add = (a, b) -> a + b;
System.out.println(add.apply(5, 3)); // 8

BiPredicate<String, Integer> checkLength = (s, len) -> s.length() == len;
System.out.println(checkLength.test("Hello", 5)); // true

BiConsumer<String, Integer> printPair = (name, age) -> 
    System.out.println(name + " is " + age + " years old");
printPair.accept("Alice", 30);
```

```java
List<String> list = new ArrayList<>(); // diamond operator
int million = 1_000_000; // underscore in literals
try (FileReader fr = new FileReader("f.txt")) { } catch (IOException e) { }
```

### 2️⃣2️⃣4️⃣ What are the new features in Java 8? 🎉🚀
The **biggest Java release** in years:
- **Lambda expressions** (`() -> {}`)
- **Streams API** (functional-style collection processing)
- **Functional interfaces** (`Predicate`, `Function`, `Consumer`, `Supplier`, etc.)
- **Default and static methods** in interfaces
- **Method references** (`::`)
- **Optional<T>** class (avoid `NullPointerException`)
- **New Date/Time API** (`java.time` — `LocalDate`, `LocalTime`, `LocalDateTime`)
- **Nashorn JavaScript engine**

```java
// Lambda + Streams (Java 8)
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.stream().filter(n -> n.length() > 3).forEach(System.out::println);

// Optional
Optional<String> opt = Optional.ofNullable(null);
System.out.println(opt.orElse("default")); // "default"

// New Date/Time API
LocalDate today = LocalDate.now();
System.out.println(today);
```
